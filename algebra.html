فرمول‌های پایه جبر

مربع اعداد

(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
a² - b² = (a - b)(a + b)

مکعب اعداد

(a + b)³ = a³ + 3a²b + 3ab² + b³
(a - b)³ = a³ - 3a²b + 3ab² - b³
a³ + b³ = (a + b)(a² - ab + b²)

معادلات درجه دوم

ax² + bx + c = 0
x = [-b ± √(b² - 4ac)] / 2a
Δ = b² - 4ac

رابطه‌های عددی

اعداد زوج و فرد

زوج + زوج = زوج
فرد + فرد = زوج
زوج + فرد = فرد
زوج × زوج = زوج
فرد × فرد = فرد

ویژگی‌های ضرب

a × b = b × a
a × (b + c) = ab + ac
a × (b - c) = ab - ac
a × 0 = 0
a × 1 = a

توان و رادیکال

aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
√(ab) = √a × √b
